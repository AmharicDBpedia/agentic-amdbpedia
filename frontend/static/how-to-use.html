የአጠቃቀም መመሪያ

የአማርኛ Wikipedia infobox-ን ወይም template-ን ወደ DBpedia ontology እንዴት እንደሚያዛምዱና የተዛመደውን {{TemplateMapping}} wikitext እንዴት እንደሚያወርዱ የሚያሳይ ዝርዝር ነው። የ DBpedia ጽንሰ-ሐሳብና ዝርዝር ዳራ ለማግኘት Documentation ገጹን ይመልከቱ።

የአጠቃቀም ፍሰት

ደረጃ በደረጃ

  1. መልዕክት ይላኩ

    በ app የመጀመሪያ ገጽ ላይ ከሚከተሉት አንዱን ይለጥፉ፦

    • የ infobox wikitext ({{Infobox …}} በቀጥታ)
    • የ Wikipedia ገጽ URL (ለምሳሌ https://am.wikipedia.org/wiki/…)
    • የ template አድራሻ (ለምሳሌ https://am.wikipedia.org/wiki/መለጠፊያ:የምግብ_መረጃ)
    • አንድ የ field ስም (ለምሳሌ አይካኦ_ኮድ)

    Groq መልዕክቱን ያነባል፣ ዓይነቱን (infobox፣ URL፣ template ወይም field question) ይለያል፣ ተገቢውን DBpedia class ይገምታል።

  2. Pipeline ይጠናቀቅ

    ከዚያ pipeline-ው 4 ደረጃዎች ውስጥ ይሄዳል፦ infobox fields ማውጣት → ontology properties መተንበይ → mapping XML ማመንጨት → run record ማስቀመጥ። ለ Wikipedia link ተጨማሪ የመጀመሪያ ደረጃ አለ፦ Wikipedia source ማምጣት። ጊዜው የሚወስደው 10–60 ሰከንድ ነው (model እና infobox-ው መጠን ላይ ተመርኩዞ)።

  3. Mapping card ይታያል

    እያንዳንዱ የ infobox መስክ አንድ ረድፍ ነው። ረድፉ በመጀመሪያ read-only ነው፦ የ DBpedia property እንደ ጽሁፍ ይታያል፣ ከዚያ ጎን ላይ ✎ (ለማረም) እና 🗑 (ለማስወገድ) buttons አሉ።

  4. ያርሙ (pencil ✎)

    የ ✎ (pencil) button ን ይጫኑ፣ የ inline editor ይከፈታል፦ የ property input፣ የ ontology search button፣ እና አረንጓዴ የ ✓ (አርትዖትን ጨርስ) button። ያርሙ ወይም search ያድርጉ፣ ከዛ ✓ ን ይጫኑ።

  5. ተረጋግጧል የሚል ምልክት

    ✓ ን ሲጫኑ editor ይዘጋል፣ "ተረጋግጧል" የሚል አረንጓዴ ምልክት ይታያል። ይህ ረድፉ በእርስዎ እንደተገመገመ ያሳያል።

  6. ያልተዛመዱ መስኮች ይጨምሩ

    pipeline-ው ያልቻላቸው መስኮች በ table ላይ ባዶ ረድፎች ሆነው ይታያሉ (dashed border)። ከታች ባሉት suggestions ውስጥ ይምረጡ፣ ወይም የ property name ይተይቡና + ን ይጫኑ፣ ወይም 🔍 በመጠቀም ontology ን ይፈልጉ። አዲስ መስክ ለማስገባት የ "+ ሌላ የመረጃ ሳጥን መስክ" ረድፍን ይጠቀሙ።

  7. Download

    ሁሉም ረድፎች ዝግጁ ሲሆኑ የ Download button ን ይጫኑ። የ {{TemplateMapping}} wikitext ተፈጥሮ እንደ Mapping_am-<template>.wiki file ይወርዳል።

  8. ወደ mappings.dbpedia.org ለጥፉ

    በ browser ላይ https://mappings.dbpedia.org/index.php/Mapping_am:<template> ን ይክፈቱ፣ login ያድርጉ፣ edit tab ን ይጫኑ፣ ያወረዱትን wikitext ይለጥፉ፣ save ያድርጉ።

    ማስታወሻ፦ በቀጥታ ከ app internally publish ማድረግ አሁን available አይደለም (publish button በኋላ ይመለሳል)። ለአሁን download → paste የሚባለው workflow ነው ጥቅም ላይ ያለው።

  • ውይይቱን አጽዳ (Clear chat): በ sidebar ላይ ያለው button ውይይቱን ያጸዳል። ያልተለቀቁ edits ካሉ ማረጋገጫ ይጠይቃል።
